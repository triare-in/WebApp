Getting started

Your keyboard runs ZMK, an open-source firmware. No companion app, no driver: it works like any Bluetooth keyboard, and changes stay on the device.

Bluetooth 5.2 · pairs with up to 3 devices
USB-C wired mode always available
Flash over USB-C with the included cable

Pairing

  1. 1 Hold the FN+Esc key for 3 seconds until the LED blinks
  2. 2 Pick Harness in your device's Bluetooth list
  3. 3 Switch profiles with the scroll knob
terminal · first run 
$ hc-tool scan — found: harness-75 (BT5.2)
$ pair — connected in 1.8s

Layers and remap

Every key lives in a config file on the board. Edit the JSON, flash over USB-C, and the change is yours — no account, no sync. A minimal remap looks like this:

json · keymap.json 
{
  "keymap": {
    "home": ["Space", "Enter", "Esc"],
    "fn":   ["Left", "Right", "Volume Up"]
  }

Macros

Bundle a sequence of keys into one. Small, useful, on-device — no cloud.

macro.copy() Selects, copies, clears the screen region
macro.window_cycle() Alt-tab through the last 3 apps
macro.pause_ms(50) Spacing between actions

Firmware updates

Updates arrive over USB-C, straight from the Harness site. No phone, no cloud.
