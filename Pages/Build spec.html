Harness Store — build spec (desktop only, dark default + light twins)

Hard rules for every frame

  • One self-contained HTML frame per screen. NO html/body wrappers, no <style>, no inline style attributes. Tailwind arbitrary values only.
  • Desktop only: frame width 1440. No mobile breakpoints, no responsive code.
  • Fonts: font-['Plus_Jakarta_Sans'] 600–700 for headings/prices; font-['Manrope'] 400–600 body; font-['JetBrains_Mono'] for order IDs, SKUs, code.
  • Sentence case. Prices ₹12,499 with [font-variant-numeric:tabular-nums]. Realistic content, no lorem. Dark theme is the default; every frame also has a light twin on the same page (frame id gets a -light suffix, header pill reads "Light"). Signed-in headers show an avatar icon, never a username.
  • EXACTLY ONE filled primary button (#6B4FBB, white) per view. Others: outline (border #D6CCE6 bg white), ghost (text), or secondary (#EFE9FA bg, text #3F2F73).
  • shadcn/ui components only: Button, Card, Input (label above), RadioGroup as selectable cards, Select, Dialog, Alert, Table, Badge, Tabs, Accordion, Toast. Selected option card = 1px #6B4FBB border + shadow-[0_0_0_1px_#6B4FBB] + filled check circle.
  • Radii: buttons/inputs 10px, cards/dialogs/drawers 16px, badges/swatches full. 1px borders #E4DDF0.
  • Shadows only: xs 0 1px 2px rgb(60 40 110/0.06); sm 0 2px 8px rgb(60 40 110/0.08); lg 0 12px 32px rgb(60 40 110/0.14).
  • Control heights 32/40/48. Container max-w-[1152px] centered. 4px grid: 4/8/12/16/24/32/48/64.
  • Icons: inline Lucide-style SVG, stroke 1.5, 16/20/24px. Never emoji.
  • Type scale: display 48, h1 36, h2 24, h3 18, body 16, small 14, caption 12 (never below 12).
  • EVERY frame must begin with the hidden defs SVG at the bottom of this document so <use href="#HM"/> and <use href="#KK"/> resolve.
  • Copy tone: plain, warm, specific; verbs on buttons; errors state what/why/fix; say "repair / swap / part".
